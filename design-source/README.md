# Design source files

Reference copies only. Nothing in this folder is served on the website.

- `logo-original-est-2025.png` — the logo as cropped from the black-and-orange menu poster, before correction. Its artwork says "EST. 2025".

The website logo (`public/images/brand/lets-eat-amigos-logo.png` / `.webp`, `public/favicon.png`, `public/apple-touch-icon.png`) is this same crop, edited to say **EST. 2024**, the confirmed founding year. Only the final "5" was replaced with a "4", drawn in a bold sans-serif matched to the existing digits; the rest of the design is unchanged.

The original menu poster (`public/images/menu/menu-poster-black-orange.jpg`) is unchanged and still says EST. 2025.
